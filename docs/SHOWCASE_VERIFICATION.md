# 研究成果展示前端验证

验证日期：2026-09-20。使用独立 PostgreSQL（55437）、独立文件目录和本地验证站点（5181），8 项模拟研究、4 类要素；未向业务数据库写入示例资料。

## 自动验证

- `npm run build`：TypeScript 和生产构建通过。
- `npm test`：18 项单元测试通过，包含同一研究右侧节点链式连接、每项研究仅两条要素关联线、布局不重叠、展开研究时核心节点位置稳定。
- `npm run test:integration`：16 项集成测试通过，包含登录权限、分组分页、停用要素历史研究、HTML 清理，以及 PDF 预览和下载响应；已有上传、数据字典、图文 PDF、LLM、启动停止测试均通过。

## 浏览器验证

在 Chrome 的 1600 × 1000、1440 × 900 与 390 × 844 视口检查：

- 登录、恢复会话及退出后重新登录均默认展示图谱。
- 前后台按钮切换正常，未保存题目草稿保留；保存后返回前端可检索到新题目。
- 同一研究四张卡片对齐，连接为“产生机制 → 要素 → 经济影响 → 潜在风险 → 政策建议”；风险和政策不再单独连回要素。悬停出现 3 个沿线移动的圆点，检测到实际位置变化。关闭动画及系统减少动态效果设置生效。
- 题目、要素和研究类型筛选可用；无结果有提示；资本研究从 3 项展开至 5 项，无重复节点。
- 缩放、适应宽度、鼠标拖动画布可用；拖动实测滚动 190 像素。
- 桌面阅读窗宽度分别为 480 / 432 像素，即视口的 30%；手机为 390 像素全宽，无页面横向溢出。
- 四章 HTML 中的标题、段落、图片、表格、引用正常显示；4 张插图均加载成功。章节按钮与直接点击风险卡片均定位正确；Escape 可关闭阅读窗。
- 论文预览在新标签页中以 `application/pdf` 打开，并实际显示 Chrome PDF 阅读器；下载文件为 `research-paper.pdf`，47,950 字节，下载无错误。
- 没有网页全文或论文时显示缺失提示，不生成虚构正文或附件入口。
- 最终浏览器控制台未出现运行错误。
